1. Creating and Renaming Files/Directories
Commands used to initialize the project structure:

mkdir test_dir
touch test_dir/example.txt
mv test_dir/example.txt test_dir/renamed_example.txt

2. Viewing File Contents
Commands to inspect system files:

cat /etc/passwd
head -n 5 /etc/passwd
tail -n 5 /etc/passwd

3. Searching for Patterns
Filtering for specific users in the system:

grep "root" /etc/passwd

4. Zipping and Unzipping
Managing compressed archives:

zip -r test_dir.zip test_dir
unzip test_dir.zip -d unzipped_dir

5. Downloading Files
Fetching external resources via the terminal:

wget https://txt2html.sourceforge.net/sample.txt

6. Changing Permissions
Securing a file by making it read-only for everyone:

touch secure.txt
chmod 444 secure.txt

7. Working with Environment Variables
Setting and verifying a shell variable:

export MY_VAR="Hello, Linux!"
echo $MY_VAR
